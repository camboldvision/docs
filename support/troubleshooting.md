# 常见问题

## Viewer 离线，找不到相机

1. 确认相机已通电、USB 线支持数据传输，优先直接连接电脑。
2. 查看文件资源管理器中的 MTP 设备和设备管理器中的相机是否出现。
3. 关闭其他 Viewer 实例和占用设备的程序。
4. 换电脑上的另一个接口和一根可靠短线。
5. 若网络可用，通过 SSH [检查服务和日志](reference/files-services.md)；网络也中断时，按本页“相机突然从 Windows 消失”排查。

当前一台电脑支持连接一台 CamBold。MTP 或 UVC 已出现但 Viewer 仍离线时，检查配套 USB 接口驱动和设备管理器中的异常设备。

## MTP 正常，但没有视频

关闭 Windows 相机或其他视频软件，再在 Viewer 中启动预览。检查系统隐私设置是否允许桌面应用访问摄像头。Linux 下检查 USB / video 权限。视频设备编号和 COM 编号都会变化，应用应自动识别设备。

## 原始画面弯曲，左右并排

原始视频包含左右两幅鱼眼图像。开启深度后，`Rectified left RGB` 显示校正左图；程序可通过 [同帧颜色与视差接口](development/depth.md) 获取校正数据。

## 开启深度后帧率下降

深度模式会限制全设备图像帧率，详见 [分辨率与帧率规则](guides/depth.md#可选分辨率与帧率)。关闭深度后，可在顶部栏重新选择图像帧率。

## 提示标定文件缺失或无效

检查 `/data/eeprom/camera_imu_calibration.yaml` 是否存在，并确认它来自当前设备。备份与更新方法见 [标定文件维护](guides/calibration.md)。

## 点云有空洞，远处不稳定

检查校正图是否清晰，以及 Viewer 的 `Depth limit (m)` 是否覆盖目标距离。玻璃、反光、无纹理区域、遮挡边缘和远处物体的深度可能无效或不稳定。

## 纯定位时没有马上出现有效位姿

让相机观察原地图中已记录、纹理明显的区域，并缓慢移动，等待初始化和地图对齐完成。状态说明见 [位姿与定位状态](guides/vio.md)。

## USB 稠密 SLAM 时不能开启 IMU 上传

电脑端 SDK 在稠密 SLAM 运行期间关闭该连接的 IMU 上传，SLAM 内部的 IMU 保持工作。停止稠密 SLAM 后，手动开启上传。板端 LOCAL SDK 允许两者同时运行。

## 改了帧率，重启后仍是较低值

帧率会保存在相机配置中，深度功能触发的降帧也会保存。停止相关功能，再从 `Frame rate` 选择目标值。

## Terminal 输入密码没有显示

Linux 终端默认隐藏密码输入，输完后按回车。`sudo` 通常使用当前账号的密码。

## 网络 SSH 连不上

在 Viewer 终端执行 `hostname -I` 核对当前 IP，并确认电脑和相机网络互通。若 SSH 提示主机密钥改变，核实设备身份和刷机情况后，更新电脑端的对应记录。

## 地图不能删除或复制后打不开

停止 SLAM 并等待保存完成后，再复制或删除文件。检查磁盘空间、目录权限和文件名，操作步骤见 [地图管理](guides/slam.md#保存、备份与删除)。

## 相机突然从 Windows 消失

先观察相机网络是否也中断。如果网络仍正常，优先检查 USB 线、接口和电脑事件；如果网络和 USB 同时失联，应检查供电与系统状态。重新连接后，可通过 [服务与日志命令](reference/files-services.md) 获取记录。如可复现，记录故障时正在使用的功能、供电方式与 USB 连接方式。
