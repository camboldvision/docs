# 术语表

| 术语 | 含义 |
| --- | --- |
| 双目 / 基线 | 两只相机共同观察场景；基线为两相机之间的距离 |
| fps / Hz | 每秒帧数 / 每秒发生次数；图像、IMU、位姿和 UI 可具有不同频率 |
| IMU | 惯性测量单元，提供加速度和角速度 |
| UVC / MJPEG | USB 视频设备协议 / 逐帧 JPEG 压缩视频 |
| MTP | 文件传输协议；本产品映射到 `/data/share` |
| ACM | USB 虚拟串口；用户在 `/dev/ttyGS2` 自定义通信 |
| 校正图 | 根据标定将原始图像变换到指定投影后的图像 |
| 视差 | 同一场景点在左右图中的位置差，单位为像素 |
| 深度 / 点云 | 到场景的几何距离 / 一组三维点，可包含颜色 |
| FP16 / RGB565 | 16 位浮点格式 / 用 16 bit 表示颜色的 5-6-5 格式 |
| FOV | 视场角，描述成像覆盖范围 |
| 位姿 / 四元数 | 位置与方向 / 表示三维旋转的一种四分量形式 |
| SLAM | 在运动过程中建立地图并估计设备位姿 |
| 关键帧 | 从连续观测中选取、用于构建地图的代表性帧 |
| 回环 / 重定位 | 再次识别已访问区域并校正地图关系 / 在已有地图中恢复定位 |
| 稀疏 / 稠密地图 | 主要保存定位点的地图 / 另保存较完整场景点云的地图 |
| SDK / API | 供用户开发的软件包 / 可调用的函数接口 |
| USB / LOCAL 后端 | SDK 在电脑通过 USB 通信 / 在相机内部访问本地服务 |
| Linux shell / SSH | 本地命令行环境 / 通过网络远程登录的协议 |
| AArch64 / 交叉编译 | ARM 64 位体系结构 / 在另一台电脑上生成目标设备程序 |
| systemd service | Linux 中负责启动和维护后台功能的服务 |
| Loader | Rockchip 固件烧录模式，日常相机功能在此时暂停 |
