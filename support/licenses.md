# 许可与文档维护

## SDK 与 Viewer

CamBold SDK 和 CamBold Viewer 的第一方代码采用 **Apache License 2.0**。完整许可随对应源码包中的 `LICENSE` 提供。第三方源码保留各自的许可与版权声明；SDK 的组件清单见源码包 `THIRD_PARTY.md`。

| 软件包 | 许可文件位置 |
| --- | --- |
| CamBold SDK | `cambold_sdk/LICENSE` |
| CamBold Viewer | `cambold_viewer/LICENSE` |
| SDK 第三方说明 | `cambold_sdk/THIRD_PARTY.md` |
| 文档站点 Docsify | [随站点分发的 LICENSE](assets/vendor/docsify/LICENSE) |
| 语法高亮 Prism | [随站点分发的 LICENSE](assets/vendor/prism/LICENSE) |

分发衍生程序时，应保留所含组件的许可与版权文件，并遵守相应许可。Apache-2.0 的授权范围为上述代码；产品名称、图标、硬件资料和图片的使用需另行确认授权。
