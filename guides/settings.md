# 设置与标定文件

## 配置保存

相机将用户配置保存到 EEPROM 文件系统中的 `/data/eeprom/camera_config.json`。建议通过 Viewer 或 SDK 修改，设备负责校验和写入。

| 配置 | 重启后 |
| --- | --- |
| 图像帧率 | 保留已设置值 |
| 天线选择 | 保留已设置值 |
| 深度模式、投影、水平焦距、垂直 FOV | 保留已设置值 |
| IMU 上传开关 | 默认关闭，需要应用重新开启 |
| 深度数据订阅 | 应用连接后按需要开启 |
| SLAM 运行状态 | 等待应用发送启动请求 |

开启深度导致帧率降低时，新的帧率也会保存。应用通过 SDK 的设备配置和深度状态接口读取当前值与可选项。

## 标定文件

默认路径为：

```text
/data/eeprom/camera_imu_calibration.yaml
```

深度与 SLAM 使用当前相机的标定文件。文件缺失或无效时，设备返回错误，Viewer 显示提醒；文件管理和原始图像功能仍可使用。

EEPROM 容量为 16 KiB，用于保存标定和少量配置。地图、程序、rosbag 等大文件放在 `/data/share`。备份与替换方法见 [标定文件维护](guides/calibration.md)。

## 修改步骤

1. 停止当前 SLAM，并等待地图保存完成。
2. 如需修改深度几何设置，先关闭深度。
3. 在 Viewer 修改参数并点击 `Apply`，或用 SDK 提交请求并检查执行结果。
4. 确认设备上报的新状态，再重新开启功能。

多个应用共享同一设备的帧率、天线和投影参数。调整这些配置会影响其他正在使用相机的应用。
