# API 总览与调用规则

API 参考覆盖 `cambold_sdk/include/cb_sdk.h` 中的 **50 个公开函数**。电脑端与板端使用相同接口，后端在编译时选择。类型和原型以公共头文件为准，未标参数名的原型按下文顺序解释参数。

## 接口分组

| 分组 | 内容 |
| --- | --- |
| [连接与设备控制](reference/api-device.md) | 创建与关闭、连接状态、设备名称、系统状态、设备配置、帧率、天线与 IMU 开关 |
| [视频与 IMU](reference/api-streams.md) | 视频回调、IMU 批次和图像元数据解码 |
| [深度](reference/api-depth.md) | 能力查询、投影配置、同帧颜色与视差、FP16 与三维坐标 |
| [SLAM](reference/api-slam.md) | 地图模式、运行控制、200 Hz 位姿、图像和地图增量 |
| [终端与板端录制](reference/api-terminal.md) | shell 输入输出、终端尺寸、板端 rosbag |
| [数据结构与事件](reference/data.md) | 每类输入输出结构体、单位、标志位和回调事件 |

## 返回值

大多数 `int` 函数以 0 表示成功、负数表示错误。字符串 getter、布尔查询、读取字节数和浮点转换具有各自约定，见具体函数。

| 返回或结果 | 处理方法 |
| --- | --- |
| `-EAGAIN` | 暂无有效或更新数据，稍后重试 |
| `-ENOSPC` | 扩大输出缓冲；仅在函数承诺时读取其回填尺寸 |
| `-EINVAL` | 检查指针、尺寸、数值和事件类型 |
| `-ENOTCONN` | 等待连接或相应功能握手就绪 |
| `-EBUSY` | 当前会话或功能限制，先释放占用或停止冲突功能 |
| `-ENOENT` | 缓存中尚无名称、状态或所请求信息 |
| `-ENOTSUP` | 当前功能或参数组合不支持 |
| `CB_STEREO_CALIBRATION_ERROR`（-2001） | 标定文件缺失或无效 |
| `CB_STEREO_MODEL_ERROR`（-2002） | 深度所需资源缺失或无效 |

errno 的数值随平台变化，跨平台代码使用错误码符号比较。

## 异步控制

一般控制请求携带 `request_id`：

1. 用 `cb_next_request_id()` 取新请求号。
2. 调用设置函数，先检查本地返回值。
3. 本地返回 0 后，等待同一请求号的 `CB_EVENT_RESULT`。
4. 检查 `event.result`，再读取相应状态事件确认设备当前值。

SLAM 命令通过 SLAM JSON 的 `state.last_result` 和运行状态确认执行结果。

## 内存与线程

| 对象 | 内存归属 | 生命周期 |
| --- | --- | --- |
| `cb_t`、`cb_video_t` | SDK | 对应 open / close 之间 |
| 事件 `payload`、`text`，视频 `jpeg` | SDK | 仅在对应回调返回前有效 |
| `cb_get_disparity` 输出数组 | 应用 | 由应用分配和释放 |
| SLAM JSON 字符串 | SDK 分配，应用负责释放 | 调用 `cb_slam_free_json()` 前有效 |

所有选项结构体先清零。视频、控制和深度事件回调可能并发，应用需同步访问共享数据。回调内完成数据复制或入队，耗时处理交给应用线程；关闭 SDK 和等待其他回调的操作也放在应用线程中。

断线后 SDK 自动尝试重连，命令不自动重放。应用收到新连接后应重新读取能力、建立所需订阅，并清理上次运行的帧号与时间缓存。退出前停止应用工作线程，再关闭视频和 SDK。

## 共享设备配置

帧率、投影、焦距和天线属于全设备配置。LOCAL 可以有多个独立采集连接，但同一时刻由一个连接控制 SLAM 及地图增量。USB 稠密 SLAM 限制本连接的 IMU 上传，LOCAL 不限制。

USB / LOCAL 是 SDK 数据通道选择；用户 ACM 和自定义协议不影响公开 API 的调用形式。
